# Security Policy

CyberPlayground is a local educational site. Its labs analyze supplied text in the browser and do not scan hosts, exploit systems, collect credentials, or make network requests.

- Never enter real passwords, API keys, cookies, or customer data.
- Do not add third-party scripts, analytics, or remote dependencies without reviewing privacy impact.
- Keep user-supplied text rendered with textContent or equivalent safe output handling.
- Report suspected vulnerabilities privately to the repository owner where private reporting is available.
